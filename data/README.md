# Data Directory

## Dataset: PaySim Synthetic Financial Transactions

**Source**: [PaySim on Kaggle](https://www.kaggle.com/datasets/ealaxi/paysim1)

**File**: `PS_20174392719_1491204439457_log.csv` (≈470 MB)

This dataset is a **synthetic** simulation of mobile money transactions generated by the PaySim simulator, based on aggregated anonymized data from a real mobile money service.

## Important

- The raw dataset is **NOT committed to this repository** (see `.gitignore`).
- Download from Kaggle and place in `data/raw/`.
- Do NOT use this dataset commercially or claim it represents real transaction data.

## Columns

| Column | Description |
|---|---|
| step | Time step (1 step = 1 hour). Range: 1–744 (31 days) |
| type | Transaction type: CASH-IN, CASH-OUT, DEBIT, PAYMENT, TRANSFER |
| amount | Transaction amount |
| nameOrig | Customer initiating the transaction |
| oldbalanceOrg | Balance of originator before transaction |
| newbalanceOrig | Balance of originator after transaction |
| nameDest | Recipient |
| oldbalanceDest | Balance of destination before transaction |
| newbalanceDest | Balance of destination after transaction |
| isFraud | Ground truth fraud label (1 = fraud, 0 = legitimate) |
| isFlaggedFraud | System flag for large illegal transfers |

## Processed Data

Files in `data/processed/` are derived features and preprocessed splits, also excluded from git.
